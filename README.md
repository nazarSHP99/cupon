# Cupon

Одноекранний інтерактивний купоноприймач на React, TypeScript, Vite та Three.js.

Повноекранна 3D-сцена: великий автомат стоїть на столі, ліворуч лежать три купони, а трохи вище — принтер чеків, з'єднаний з автоматом проводом. При наведенні демокупони піднімаються. Вибір файлу оформлено як купон у правому нижньому куті. Кнопка вставляння з'являється над нижніми кроками «Обери → Встав → Усміхнись». Основний текст інтерфейсу має розмір від 14 px.

## Запуск

Потрібен Node.js 22.12+.

```sh
npm install
npm run dev
```

Відкрити адресу, яку надрукує Vite (зазвичай http://127.0.0.1:5173).

```sh
npm run build
npm run preview
```

## Сценарій

1. Завантаж PNG або SVG до 10 МБ, перетягни файл у зону завантаження, натисни на один із купонів на столі або обери «Спробуй демокупон».
2. Перетягни 3D-купон до помаранчевої щілини й відпусти або натисни «Вставити купон».
3. Автомат затягує купон. Принтер плавно друкує чек активації; модального вікна немає.
4. «Зберегти чек» завантажує PNG 900 × 1340 px з оригінальним зображенням купона, назвою, датою, номером чека та нагадуванням виконати обіцянку. Чек можна надіслати тому, хто подарував купон.
5. Кнопка повторної спроби прибирає чек і повертає початковий стан.

Назва власного купона береться з назви файлу без розширення; текст усередині зображення не розпізнається. Оригінальний дизайн зберігається на чеку. Для іншого підпису достатньо перейменувати файл перед завантаженням.

Файли обробляються локально. SVG растеризується у браузері; зовнішні ресурси та скрипти не приймаються. Текстури зменшуються до максимум 2048 px по довшій стороні. Зображення довільного співвідношення сторін зберігає свої пропорції.

Активація демонстраційна: бекенду, реєстру купонів, розпізнавання кодів і захисту від повторного використання ще немає. Кожне підтримуване зображення проходить демонстраційний сценарій.

За замовчуванням звук вимкнено. Є підтримка `prefers-reduced-motion`, керування основним сценарієм з клавіатури та запасний інтерфейс, якщо WebGL недоступний.

## Власні матеріали

- `public/demo-coupon.svg` — демокупон.
- `public/demo-good-things.svg`, `public/demo-happy-moment.svg` — інші купони зі стосу.
- `src/MachineScene.tsx` — геометрія автомата, матеріали, камера й анімація купона.
- `src/ReceiptPrinter.ts` — принтер і геометрія паперу, який виходить зі щілини.
- `src/receipt.ts` — формування чека, його зміст і завантаження PNG.
- `src/sceneLayout.ts` — кадрування сцени й розташування керування на різних екранах.
- `src/styles.css` — стилі та адаптивність.
- `src/coupon.ts` — перевірка й підготовка зображення.

## Vercel

Проєкт підготовлено як статичний Vite-застосунок. У Vercel обрати **Vite**, команда збірки — `npm run build`, папка результату — `dist`. Публікацію з цього проєкту ще не виконано.
