# Cupon

Одноекранний інтерактивний купоноприймач на React, TypeScript, Vite та Three.js.

Повноекранна 3D-сцена з трьома точками прокрутки — краєвид, робочий стіл і шухляда використаних купонів. Ліворуч на столі стоїть контейнер із 24 готовими купонами, складеними вертикально. Натискання наближає камеру до колекції. Під час наведення картка піднімається в стосі, а ліворуч з’являється її прев’ю. Під стосом є кнопки перегортання й завантаження купона як PNG. Праворуч лежить картка з інструкцією. Курсор миші має вигляд крапки з кільцем.

## Запуск

Потрібен Node.js 22.12+.

```sh
npm install
npm run dev
```

Відкрити адресу, яку надрукує Vite (зазвичай http://127.0.0.1:5173).

```sh
npm run build
npm run preview
```

## Сценарій

1. Прокрути до стола або натисни точку «Стіл» зверху. Завантаж PNG або SVG до 10 МБ через File чи відкрий контейнер готових купонів. Колекція також доступна через Demo. Натисни на прев’ю, щоб узяти купон, або поза стосом і прев’ю, щоб повернутися до стола.
2. Перетягни 3D-купон до помаранчевої щілини й відпусти або натисни «Вставити купон».
3. Автомат затягує купон. Принтер плавно друкує чек активації; модального вікна немає.
4. «Зберегти чек» завантажує PNG 900 × 1340 px з оригінальним зображенням купона, назвою, датою, номером чека та нагадуванням виконати обіцянку. Чек можна надіслати тому, хто подарував купон.
5. Кнопка повторної спроби прибирає чек і повертає початковий стан.
6. Прокрути далі до шухляди. Вона відкриється, і всередині з’являться до 12 останніх використаних купонів.

Історія зберігається в localStorage цього браузера й відновлюється після перезавантаження. Для власних купонів зберігається зменшена копія зображення. Очищення даних сайту видаляє історію. Якщо сховище недоступне або заповнене, інтерфейс повідомляє про це й тримає запис у поточній сесії.

Назва власного купона береться з назви файлу без розширення; текст усередині зображення не розпізнається. Оригінальний дизайн зберігається на чеку. Для іншого підпису достатньо перейменувати файл перед завантаженням.

Файли обробляються локально. SVG растеризується у браузері; зовнішні ресурси та скрипти не приймаються. Текстури зменшуються до максимум 2048 px по довшій стороні. Зображення довільного співвідношення сторін зберігає свої пропорції.

Активація демонстраційна: бекенду, реєстру купонів, розпізнавання кодів і захисту від повторного використання ще немає. Кожне підтримуване зображення проходить демонстраційний сценарій.

За замовчуванням звук вимкнено. Є підтримка `prefers-reduced-motion`, керування основним сценарієм з клавіатури та запасний інтерфейс, якщо WebGL недоступний.

## Власні матеріали

- `src/coupons/catalog.ts` — тексти й SVG-дизайн 24 готових купонів.
- `src/hooks/useCouponHistory.ts` — локальна історія використання купонів.
- `src/app/` — інтерфейс і стилі. Спільні елементи інтерфейсу лежать у `src/components/`.
- `src/hooks/` — React-хуки для звуку й налаштування анімації. Відтворення звуку лежить у `src/audio/`.
- `src/coupons/` — перевірка зображень купонів і формування чеків.
- `src/scene/` — камера, кадрування й анімація купона. Моделі стола, клавіш, дисплея та принтера лежать у `src/scene/terminal/`.
- `src/scene/meadow/` — рельєф, небо, трава та квіти.

## Vercel

Проєкт підготовлено як статичний Vite-застосунок. У Vercel обрати **Vite**, команда збірки — `npm run build`, папка результату — `dist`. Публікацію з цього проєкту ще не виконано.
